# Estudos de Redes de Computadores

## Sobre o projeto

Este repositório foi criado para organizar meus estudos no curso de Tecnologia em Redes de Computadores da Gran Faculdade.

## Objetivos

- Aprender conceitos fundamentais de redes.
- Estudar endereçamento IP.
- Conhecer equipamentos de rede.
- Registrar atividades e projetos práticos.

## Tecnologias e conceitos

- Redes LAN e WAN
- Protocolo TCP/IP
- Endereçamento IPv4
- Switches e roteadores
