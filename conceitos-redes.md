# Conceitos Básicos de Redes de Computadores

## 1. O que é uma rede de computadores?

É um conjunto de dispositivos conectados para compartilhar informações e recursos.

## 2. O que é um endereço IP?

É um endereço lógico utilizado para identificar uma interface em uma rede IP.

Exemplo de IPv4: 192.168.1.10

## 3. Switch

Equipamento que encaminha quadros dentro de uma rede local, usando endereços MAC.

## 4. Roteador

Equipamento que encaminha pacotes entre redes IP diferentes.

## 5. LAN e WAN

- LAN: rede de área local, como a rede de uma casa ou empresa.
- WAN: rede de longa distância, que interliga redes em áreas geográficas maiores.

## 6. TCP e UDP

- TCP: protocolo de transporte orientado à conexão, com mecanismos de entrega confiável.
- UDP: protocolo de transporte sem conexão, com menos mecanismos de controle.
